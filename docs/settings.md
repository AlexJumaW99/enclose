# Settings

The gear at the bottom left, or Cmd+,. Esc, or Back, returns to the model.

| Section | What it holds |
|---|---|
| General | Where new projects are saved, `~/Documents/Enclose` to begin with |
| | Whether Claude [looks over](projects.md#claude-looks-the-model-over) the CAD files you open |
| | How much Claude [may do without asking](working-with-claude.md#model-effort-and-access) |
| | After how many days a [conversation](working-with-claude.md#conversations) left alone goes under its project's card |
| | What a [blueprint](blueprints.md#exploded-and-dimensions)'s dimensions are in, millimetres or inches |
| Appearance | The theme: the system's, light or dark |
| Navigation | How a scroll is read (automatic, trackpad or mouse), and how fast the view turns |
| Shortcuts | [Every shortcut](shortcuts.md) |
| Providers | The [agents](working-with-claude.md#other-agents) the app can put a message to, and for each the binary to run, where it keeps its settings and sign-in, the arguments and variables it is started with, and which of its models the message box offers |
| About | The app's version |
